# Ordinary ground traversal provenance

`src/terrain-traversal-ground.ts` is original WebRA2 TypeScript, distributed as
**GPL-3.0-or-later** because it composes the existing GPL content/format pipeline.
Tests are original synthetic maps/INI/TMP bytes and expected behaviors. No retail
code, tables, geometry, strings or disassembly are included. See
[licensing](../../docs/licensing.md) and the
[base traversal notice](TERRAIN_TRAVERSAL_PROVENANCE.md).

## Private static native evidence

Read-only PE section mapping and Capstone5.0.6 disassembly pinned both supplied
images. These metadata rows cover complete instruction sequences, except explicitly
marked data; a short window is not a claim of a complete function. Address ends
are exclusive. Complete shared height helpers are RA2`4C8730–4C8937` and
YR`4D9C60–4D9E67`. Their ordinary branch accepts level equality or a one-level
difference with the lower endpoint's nonzero slope. Bridge/direction-sentinel
branches remain outside the WebRA2 policy. Infantry/Unit vtable assignments,
entries and callers establish use of this shared stage in both profiles; later
collision and locomotor stages are not elided by that finding.

Packed-map loading stores the level byte in Cell+`11B`; the selected TMP slope
getter reads header+`2A` and stores Cell+`11C`. The ordinary no-overlay terrain
path obtains its land code from TMP header+`29`. The valid-slot branch bypasses
the missing-slot cliff-back fallback. Extra-image dimensions feed Cell+`11D`,
a separate derived image-height field, not the packed-map level; its complete downstream uses remain unproved. The new component's
ordinary ground policy does not claim full native image-height, bridge or overlay
semantics. Missing TMP slots already fail in the genuine base compiler.
