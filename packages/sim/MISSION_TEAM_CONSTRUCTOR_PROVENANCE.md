[team activation](../content/TEAM_ACTIVATION_PROVENANCE.md),

The source catalog proves complete ordinary unit membership, constructor guards,
initial count classification and structural birth provenance. Source-derived
population is inserted between saved transfer revisions by the owned world-9
migration. Current actor, navigation and capability identity remains checked by
genuine factories; common source receipts are still not mission execution authority.

The paired static tag proof extends previously reviewed placement/count evidence:
Object initializes its tag pointer to null; Team initializes its tag to null and
allocates one only for a nonnull TeamType tag; AddMember skips tag replacement
when the Team tag is null. Nonempty or unresolved source tags remain gated. This
is static native observation, not execution or an assertion about every constructor.
Atomic waypoint placement, permanent source-derived IDs, one script update per tick
and birth/transfer revision ordering are WebRA2 D03 policies. Unit-only admission
does not prove spawned combat, infantry subcells, trigger attachment or full mission
behavior. The [focused report](../../docs/mission-team-constructors.md) records
validation scope and limitations.
